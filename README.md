# Gender Reveal

![Badge: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

## Description

This gender reveal site is an easy, eco-friendly way to guess the gender of your new bundle of joy! So many gender reveals go wrong, whether the balloons fly away or sparks cause an unwanted fire, this site is hassle free.
